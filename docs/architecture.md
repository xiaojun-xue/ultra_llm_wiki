# LLM Wiki 架构设计文档

## 1. 系统定位与目标

LLM Wiki 是一个**知识库检索系统**，旨在为技术文档、源代码、原理图提供统一的语义检索能力。它的核心价值在于：

1. **语义搜索** — 不是关键词匹配，而是理解查询意图的向量检索
2. **知识关联** — 自动发现文档间的隐含关系
3. **MCP 集成** — Claude Code 可直接查询知识库

> **注意**：当前系统是"LLM-Powered Search Engine"，而非传统 Wiki（无内容编辑/版本管理/LLM生成内容）

## 5. 核心技术选型

### 5.1 后端框架

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| Web 框架 | FastAPI | 异步优先、自动 OpenAPI 文档、类型安全 |
| ORM | SQLAlchemy 2.0 | 类型提示完善、async 支持 |
| 数据库驱动 | asyncpg | PostgreSQL 异步驱动 |
| JWT | python-jose | JWT 编解码 |
| 密码哈希 | passlib + bcrypt | 安全密码存储 |
| MCP 框架 | FastMCP | Python MCP SDK |
| 验证 | Pydantic v2 | 自动请求/响应验证 |

### 5.2 数据存储

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| 主数据库 | PostgreSQL 16 | 支持 JSONB、向量、全文检索 |
| 向量引擎 | pgvector | PostgreSQL 内置向量索引 |
| 对象存储 | MinIO | S3 协议兼容、自托管 |
| 缓存/队列 | Redis 7 | 任务状态、TTL 缓存 |

### 5.3 前端

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| 框架 | Next.js 14 | App Router、SSR/CSR 混合 |
| UI 库 | Tailwind CSS | 原子化 CSS、快速开发 |
| 图可视化 | D3.js / Canvas | 力导向图、知识图谱 |
| 安全渲染 | DOMPurify | XSS 防护 |

### 5.4 Embedding

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| 模型 | BGE-M3 | 多语言支持(中英)、1024 维向量 |
| 服务 | Ollama | 本地部署、无 API 费用 |
| 向量维度 | 1024 | BGE-M3 默认维度 |

## 6. 关键设计决策

### 6.1 为什么用 MinIO 而不是直接存文件系统？

- **S3 协议**：未来可迁移到 AWS S3/Cloudflare R2
- **统一 API**：前端、Python、备份工具共用
- **元数据管理**：内置 content-type、ETag

### 6.2 为什么用 pgvector 而不是独立向量数据库？

- **事务一致性**：文档内容和向量在同一个事务
- **运维简单**：减少一个服务依赖
- **RRF 融合**：在数据库层做混合检索更高效

### 6.3 为什么 MCP 用 SSE 而不是 WebSocket？

- MCP 协议官方推荐 SSE
- SSE 单向更适合"请求-响应"模式
- WebSocket 更适合双向实时通信（未来扩展）

### 6.4 为什么不做 LLM 渲染/Wiki 编辑？

- **当前定位**：检索引擎而非内容管理
- **复杂度**：Wiki 编辑需要版本控制、冲突解决、权限细分
- **可扩展**：架构上可未来添加

## 8. 安全性设计

### 8.1 认证机制

- **JWT Bearer Token**：30 分钟有效期
- **HttpOnly Cookie**：防 XSS（未来方向）
- **Token 黑名单**：Logout 后 Redis 记录失效 token

### 8.2 权限模型

| 角色 | 搜索 | 上传 | 删除自己 | 删除任意 | 管理用户 |
|------|------|------|---------|---------|---------|
| External | 仅授权文档 | 需审核 | ❌ | ❌ | ❌ |
| Internal | 全部文档 | ✅ | ✅ | ❌ | ❌ |
| Admin | 全部文档 | ✅ | ✅ | ✅ | ✅ |

### 8.3 CORS 策略

当前 `allow_origins=["*"]`，生产环境应限制为已知域名。
